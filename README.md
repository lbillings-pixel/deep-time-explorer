# Deep Time Explorer

Enter a place and explore its geological history, as far back as the evidence reliably goes.

For each stretch of deep time the site shows an illustrated scene of what the place was probably like, a short story grounded in the data for that spot, the great events of the wider world, and a globe showing where the place lay on the ancient Earth. Every scene is labeled as representative, and every text and picture has its caveats and sources one or two clicks away.

A static website: no server, no accounts, no keys, no AI calls at run time. Nearly all the data ships with the site.

## Who made this

Deep Time Explorer was made by Lee Billings, who directed and edited it and built it with Claude, an AI model made by Anthropic. Claude wrote the code, including the code that draws the scenes and paints the pictures, and researched and drafted the texts from the published sources they cite.

## Run it on your computer

You need Node.js. From this folder:

```
npm install
npm run dev
```

Then open http://localhost:5173 in a browser. Press Ctrl+C to stop it. (In Windows PowerShell, type `npm.cmd` in place of `npm` if `npm` is refused.)

- The timeline: http://localhost:5173
- The scene workbench (any scene type in any chapter, and every part): http://localhost:5173/scenes.html

## Other commands

| Command | What it does |
| --- | --- |
| `npm test` | Runs the automated tests, including the 14 test places. |
| `npm run build` | Checks the code and builds the finished site into `dist/`. |
| `npm run data` | Rebuilds the shipped data files from their sources. Slow, and rarely needed. |

## Where things are

| Path | Contents |
| --- | --- |
| `index.html`, `about.html`, `credits.html`, `scenes.html` | The pages: the explorer, what it is and its limits, its sources, and the scene workbench. |
| `src/main.ts`, `src/explore.ts` | The explorer page, and the gathering of evidence for a place. |
| `src/match/` | The time chapters, the environment taxonomy, the matching rules, and the events: extinctions, turning points, mountain building and the opening of oceans. |
| `src/geo/` | Past positions (plate models) and ancient land and sea. |
| `src/data/` | Readers for rock units, regional columns, fossil sites and geological provinces. |
| `src/scenes/` | The scenes, drawn by code: one composition per environment type, the parts library (`parts/`), the whitelist that says when and where each part may appear (`whitelist/`), and the gentle motion (`motion.ts`). |
| `src/globe/` | The ancient globe, and the globe for dropping a pin. |
| `src/stories/` | Story text and its caveats: one file per chapter, the local sentences built from data, and plain-language fossil labels. |
| `tools/` | Scripts that build the shipped data files, draw parts and scenes to pictures (`preview/`), and paint the pictures of extinctions and turning points (`extinctions/`). |
| `public/data/` | The shipped data files. Generated: do not edit by hand. |
| `public/extinctions/` | The paintings of extinctions and turning points. Generated by `tools/extinctions/`. |
| `tests/` | Automated tests and saved responses for the test places. |
| `docs/research/` | Research notes behind the texts and pictures: what each claim rests on, and what could not be checked. |

## Data sources

Macrostrat (CC BY 4.0), the Paleobiology Database (CC0), the PALEOMAP PaleoDEMs of Scotese & Wright (2018, CC BY 4.0), three plate models obtained through the GPlates Web Service (PALEOMAP and Merdith et al. 2021, both CC BY 4.0; Golonka as updated by Wright et al. 2013, CC BY 3.0), the geological provinces of Hasterok et al. (2022, CC BY 4.0), and GeoNames (CC BY 4.0). `credits.html` lists every source, what it supplies and the terms it is used under; each location page lists the sources behind what it shows.
